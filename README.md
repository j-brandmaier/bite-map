# Bite Map

An Android app that logs our toddler's meals and preferences and flags when we're stuck in a rut.

My husband and I want to raise an adventurous eater, not what we jokingly call a "chicken nugget kid." As two working parents, we kept cooking the same meals because we couldn't keep track of what we'd made recently.

I wrote the requirements, made the product trade-off decisions, and tested the app, using Claude Code for implementation.
